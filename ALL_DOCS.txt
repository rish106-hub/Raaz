🚀 YOUR NEXT STEP: RUN THE ANDROID APP

You asked: "Help me run this app now locally! Not the backend server"

Follow this plan:

  STEP 1: Install Android Studio (10 min)
  $ brew install --cask android-studio

  STEP 2: Create Android Emulator
  $ open -a "Android Studio" .
  → Tools → Device Manager → Create Device
  → Select Pixel 6 or newer, API 34
  → Click "Finish" then play icon to start

  STEP 3: Start Backend (in Terminal 1)
  $ make run
  ✓ Server runs at http://localhost:8080

  STEP 4: Run App (in Terminal 2)
  $ open -a "Android Studio" .
  → Click green Play button (▶️)
  → Select your emulator
  → Click "Run"
  → Wait ~30 seconds for build
  → App launches! 🎉

💡 KEY CONCEPTS

Backend (Go):
  • Runs on http://localhost:8080
  • WebSocket server at /ws
  • In-memory or PostgreSQL+Redis storage
  • Moderation, matching, strike system

Frontend (Android/Kotlin):
  • Jetpack Compose UI (modern, interactive)
  • Connects to backend via WebSocket
  • Uses 10.0.2.2:8080 when in emulator
  • Real devices need your machine's IP

Connection:
  • App auto-connects to backend on launch
  • Emulator: ws://10.0.2.2:8080/ws
  • Real device: ws://192.168.x.x:8080/ws

🚨 COMMON ISSUES & SOLUTIONS

Issue: "Android SDK not found"
→ Solution: brew install --cask android-studio

Issue: "Backend won't connect from app"
→ Solution: Ensure make run is running in another terminal

Issue: "Emulator won't start"
→ Solution: Enable virtualization in BIOS or use physical device

Issue: "app/src/main/java directory not found"
→ Solution: Android Studio needs to open project and sync Gradle
