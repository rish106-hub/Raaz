🎯 QUICK REFERENCE

  Backend:
  $ make run              → Start server at http://localhost:8080/health
  $ make docker-up        → Start with PostgreSQL + Redis
  
  Android:
  $ ./gradlew build       → Build APK
  $ ./gradlew installDebug → Install on device
  $ adb logcat            → View logs
  $ adb devices           → List connected devices
  
  Troubleshooting:
  $ adb logcat | grep raaz        → View app logs
  $ adb kill-server               → Reset ADB
  $ emulator -list-avds           → List emulators
