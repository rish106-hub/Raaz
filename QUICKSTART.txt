🚀 OPTION 1: RUN LOCALLY (NO DATABASE)

   $ make run
   
   Or directly:
   $ ./raaz-server
   
   ✓ Server runs at http://localhost:8080
   ✓ Uses in-memory storage (data lost on restart)
   ✓ Perfect for testing WebSocket flows

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🐳 OPTION 2: RUN WITH DOCKER (PostgreSQL + Redis)

   Prerequisites:
   • Open Docker Desktop (search "Docker" in Spotlight)
   • Wait for Docker daemon to start (~30 seconds)

   Then run:
   $ make docker-up
   
   ✓ PostgreSQL running on localhost:5432 (user: raaz, db: raaz)
   ✓ Redis running on localhost:6379
   ✓ Server running on http://localhost:8080
   ✓ Persistent data stored in PostgreSQL
   
   Stop with:
   $ make docker-down
   
   View logs:
   $ make docker-logs

   $ make fmt                # Format code

🔧 ENVIRONMENT

   File: .env (created automatically)
   
   DATABASE_URL=postgres://raaz:changeme@postgres:5432/raaz?sslmode=disable
   REDIS_URL=redis://redis:6379
   POSTGRES_PASSWORD=changeme
   PORT=8080
   LOG_FORMAT=json

   Change any value and restart the server.

🚨 TROUBLESHOOTING

   Issue: "port 8080 already in use"
   → Change PORT in .env or: $ lsof -i :8080 && kill -9 <PID>

   Issue: "docker: command not found"
   → Docker Desktop not installed or not in PATH
   → Install: brew install docker (already done)
   → Or use: docker-compose (if installed separately)

   Issue: "Cannot connect to PostgreSQL"
   → Ensure docker-compose up succeeded
   → Check: docker-compose ps

   Issue: "Tests failing with WebSocket errors"
   → Normal for parallel tests. Run: make test-race
